    Tela de Alteração de Senha Fluxo do Sistema — Alteração de Senha

    Objetivo A funcionalidade de alteração de senha permite que o usuário defina uma nova senha para sua conta de forma simples e segura. Este documento apresenta o fluxo realizado pelo usuário desde o preenchimento da nova senha até a confirmação da alteração e o retorno para a tela de login.

    Visão Geral 1 - Acessar a tela de definição de nova senha 2 - Informar a nova senha 3 - Repetir a nova senha 4 - Selecionar Confirmar 5 - O sistema valida as informações 6 - O sistema redefine a senha 7 - O sistema apresenta a mensagem de sucesso 8 - O usuário seleciona Voltar para o login

    Fluxo da Funcionalidade

    Nesta etapa, o usuário deve informar uma nova senha para sua conta e repetir a senha no campo de confirmação. A tela apresenta dois campos principais: Nova senha: campo utilizado para informar a nova senha. Repetir nova senha: campo utilizado para confirmar a senha escolhida. Também estão disponíveis:

    opção para visualizar ou ocultar a senha; botão Confirmar; opção Voltar para o login. A interface também informa que a senha deve possuir no mínimo 8 caracteres, incluindo letras e números. Preenchimento dos dados Após acessar a tela, o usuário deve preencher os campos necessários. Nova senha O usuário informa a senha que deseja utilizar na conta. Repetir nova senha O usuário informa novamente a senha escolhida para confirmar o valor digitado anteriormente. Essa etapa evita que uma senha seja alterada com um valor digitado incorretamente. Confirmação da alteração Depois de preencher os campos, o usuário seleciona o botão: Confirmar A partir dessa ação, o sistema verifica as informações fornecidas e, estando de acordo com os requisitos definidos para a funcionalidade, realiza a alteração da senha.

    A tela informa ao usuário que sua senha foi alterada com sucesso e que ele já pode acessar sua conta normalmente. Nessa etapa, o sistema disponibiliza o botão: Voltar para o login

    Retorno para o login Ao selecionar Voltar para o login, o usuário é direcionado novamente para a tela de autenticação.

    A partir desse momento, o usuário poderá utilizar a nova senha para acessar sua conta.
